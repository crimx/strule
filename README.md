Strule defines a compact, portable format for user-configurable string validation rules.
Rules can be created in a visual editor, transferred through APIs, stored in databases, and evaluated consistently by different runtimes.

The project provides:

- the Strule specification
- a shared conformance test suite
- reference implementations
- rule editor examples

## Install

```
npm add strule
```
